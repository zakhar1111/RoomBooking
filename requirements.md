## Requirements 

1. A hotel contains multiple rooms. Each room has a unique room number and is located on a specific floor.

2. Guests can create bookings by selecting:

   * Check-in date
   * Check-out date
   * Number of adults
   * Number of children

3. A single booking can include one or more rooms.

4. Every room belongs to a room type (e.g., Standard, Deluxe). The room type defines the room size and available features.

5. Room types have predefined features such as TV, air conditioning, kettle, or coffee machine. All rooms of the same type share the same features.

6. Each room type has a predefined bed configuration, including bed types and quantities (e.g., one king bed, two single beds).

7. Every room type has a standard nightly rate.

8. Guests can purchase optional extras, such as:

   * Breakfast
   * Valet parking
   * Flexible refund option
   * Mini-bar usage

   Extras may be purchased during booking or during the stay.

9. The booking total is calculated using:

   * Number of rooms
   * Length of stay
   * Room type rates
   * Selected extras

10. The system tracks the payment status of each booking.

11. The system tracks room availability and housekeeping status, including:

* Available
* Dirty / needs cleaning
* Clean and ready for guests

12. Guests must provide their:

* Name
* Email address
* Phone number

when creating a booking.
